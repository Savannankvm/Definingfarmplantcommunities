# Definingfarmplantcommunities
This repository includes code and metadata for the paper titled "A plant community ecology approach to defining habitats for assessing biodiversity on farms".

The file titled: "FSE_Metadata_Appl_Veg_Sci" contains the metadata for the Farm Scale Evaluation Trial (FSE) field survey, including results from the various analyses carried out throughout this study.

The file titled: "Farm4Bio_METADATA_Appl_Veg_Sci" contains the metadata for the Farm4Bio field survey, including results from the various analyses carried out throughout this study.

The file titled: "SvM_FSE_File_Duplicates_Removed_Code_Appl_Veg_Sci" contains code that was used to remove the duplicates from the original FSE data file. The resulting file, with duplicates removed, was incorporated into the metadata provided in this repository.

The file titled: "SvM_FSE_CCA_Work_Appl_Veg_Sci_Vo1" contains code that was used to run the Canonical Correspondence Analysis (CCA) for the FSE data, as well as to create associated plots.

The file titled: "SvM_Farm4Bio_Work_Appl_Veg_Sci" contains code that was used to run the Canonical Correspondence Analysis (CCA) for the Farm4Bio data.

The file titled: "SvM_FSE_RMAVIS_Work_Appl_Veg_Sci" contains code that was used to run RMAVIS analyses on FSE data.

The file titled: "SvM_Farm4Bio_RMAVIS_Work_Appl_Veg_Sci" contains code that was used to run and RMAVIS analysis on the Farm4Bio data.

The file titled: "SvM_Vegclust_Indval_Biodiversity_Indices_Work_Appl_Veg_Sci_Vo1" contains code that was used to run: 1) parameterisation of vegclust models to decide on the most appropriate model for the FSE dataset; 2) examining the results of the chosen model to determine cluster communities; 3) running Indval analyses on the FSE data; 4) calculating biodiversity indices for the FSE data; and 5) running a vegclass analysis on the Farm4Bio data to identify presence of previously established cluster (FSE) communities in the Farm4Bio dataset.
