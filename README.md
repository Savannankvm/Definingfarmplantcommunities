# Definingfarmplantcommunities
This repository includes code and metadata for the paper titled "A plant community ecology approach to defining habitats for assessing biodiversity on farms".

The file titled: "FSE_Metadata_Appl_Veg_Sci" contains the metadata for the Farm Scale Evaluation Trial (FSE) field survey, including results from the various analyses carried out throughout this study.

The file titled: "Farm4Bio_METADATA_Appl_Veg_Sci" contains the metadata for the Farm4Bio field survey, including results from the various analyses carried out throughout this study.

The file titled: "SvM_FSE_CCA_Work_Appl_Veg_Sci_Vo1" contains code that was used to run the Canonical Correspondence Analysis (CCA) for the FSE data, as well as to create assocaited plots.
